# Packaging version compétition

## Contenu recommandé pour la remise

- build desktop Windows/Linux
- dossier `data/maps/` avec au moins une carte de démonstration
- `README.md`
- capture d'écran du menu principal
- capture d'écran du gameplay
- si visé : dossier de preuve du processus artistique

## Vérifications avant export

- les scènes démarrent depuis `Main.tscn`
- l'import `map.txt` fonctionne
- la simulation va jusqu'au résultat
- `actions.txt` est généré
- les paramètres persistent entre deux lancements
- aucun chemin `res://` ne manque
